范围合适，保留现有 canonical URL 的语言策略也正确：三个中文产品根路径继续提供中文并自引用 canonical；英文首页链接对应 `/en/`；语言切换使用可抓取的真实链接。

**实施前必须明确 FondFont 根路径的行为，不能留下“保留或替换自动跳转”的悬案。** 本轮将 `/fondfont/` 固定为稳定的英文别名页，取消自动跳转，保留 canonical 指向 `/fondfont/en/`；站内英文入口和各语言页的 hreflang 英文目标统一使用 `/fondfont/en/`，sitemap 排除别名。这适合当前静态构建范围，也不依赖简报未提供的托管重定向配置。继续自动跳转会让访问入口、实际落地语言与 canonical 的关系不稳定，并可能覆盖用户明确选择的语言。

验证器应允许这个已知的非自引用 canonical 别名，同时检查所有 sitemap、canonical 和 hreflang 目标在最终构建产物中真实存在，尤其是扁平化后的隐私页面。JSON-LD 可以保留在范围内，但不应成为本轮完成的核心标准，也不要把缺少富结果必需字段的标记视为富结果资格。
