# 免费宠物成品候选 — 2026-10-07

用户要求免费。此轮仅调查与视觉筛选；没有下载模型、安装插件、注册账户或替换网站。下列均不代表已测试可直接在 Three.js 上线。

## 优先候选

1. **Autumn — Blender Studio / Spring**
   https://studio.blender.org/characters/autumn/v1/
   已在实际页面核验 Free、Download61.2MB、CC BY4.0链接、BlenRig与particle hair信息，并查看角色预览。小型梗犬，专业动画电影的风格化角色，外观是本轮最强免费犬候选。需将毛发、材质、控制骨骼转换为实时用途，未确认附带可直接循环的步态片段。网页正文署名写作Einar Rig，似模板错误；实际使用应按下载包与官方信息保留正确来源，不能照抄错误名称。
   缩略图：https://studio.blender.org/files/public/thumbnail/97/97108c7a70aef830ef9b3f185442307e/97108c7a70aef830ef9b3f185442307e.png

2. **Domestic cat, rigged — Paweł Wałasiewicz / Blendkit (formerly BlenderKit)**
   https://www.blendkit.com/asset-gallery-detail/6b3bbcc7-db99-4424-9436-8e6678ee9354/
   实际详情页标Free、RoyaltyFree、11,056 polygons、30.7MiB、可选毛发、basic reverse IK。已查看虎斑家猫实际预览。仅确认可摆姿骨骼，没有验证完成的行走/跑步动作。适合作为猫的造型候选，但RoyaltyFree许可对资产提取有限制，公开GLB分发条件未解决。

3. **Shiba — zixisun02 / Sketchfab**
   https://sketchfab.com/3d-models/shiba-faef9fe5ace445e7b2989d1c1ece361c
   实际页面确认免费与CCBY4。More model information弹窗确认FBX、转换GLB/glTF、3MB、4.3k triangles、单纹理材质；Animations0、Rigged geometriesNo。需补骨骼和动画；不能写成免费带动画柴犬。此轮没有完成完整模型视角的视觉检查，作为轻量备选，不凭下载量断言质量。
