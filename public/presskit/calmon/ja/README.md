## アプリについて

Calmon は Mac のウインドウをスクロールできる列に整理します。同じアプリのウインドウを重ね、列を固定し、マウスでもキーボードでも切り替えられます。

macOS 26 以降

上下に配置してください。横並びでは共有する境界がスクロールを妨げ、列の切り替えはそこで先頭に戻ります。左右両側にディスプレイがある場合、背面のウインドウは選択中のウインドウの後ろに重なります。

\` で次のディスプレイにフォーカスします。Shift + \` でフォーカス中のウインドウをそのディスプレイの現在のデスクトップに移動し、そのウインドウに追従します。

ベータ期間中は無料

不具合やアイデアは X の @lazyapps へ。Calmon の改善にご協力いただき、ありがとうございます。

ウインドウは横方向にスクロールします。選択した列が画面の大部分を使います。リーダーモードでは矢印キーで移動できます。

1 列を上下に最大 3 つの領域に分け、複数のウインドウを同時に表示できます。各領域には 1 つのウインドウ、または同じ App のウインドウのスタックを配置できます。

同じ App のウインドウを 1 つの領域に重ね、1 度に 1 つ表示します。ウインドウ上部のスタックのマークをクリックするか、⌘\` で切り替えます。

リーダーモード: Space → J / X — 選択中のウインドウを同じ App のスタックに追加／スタックから外す。

列を左右どちらかの端に固定します。他のウインドウはその横をスクロールします。リーダーモードでは Tab でフォーカスを切り替えます。

最大 10 個のアプリを固定できます。Pin Deck のマークから追加し、アイコンのメニューから削除します。順序はすべてのディスプレイで共通です。

Sky Deck にはフローティングウインドウ、Max Deck には macOS 標準のフルスクリーンウインドウが並びます。アイコンをクリックすると戻れます。

デスクトップ番号をクリックして切り替えます。リーダーモードでアイコンのラベルを入力するとウインドウを選べます。Shift と 1–9 で選択中のウインドウを別のデスクトップへ移動します。

タブバーのアイコンをクリックしてウインドウを選びます。 Control を押しながらクリックすると操作メニューが開きます。 レイアウトマップをクリックするとキーパネルが開きます。 パネルのキーをクリックするとコマンドを実行します。

自動表示を止めるには、設定 → キーボード → キーパネル → 表示までの時間 → しない、を選びます。レイアウトマップからはいつでも開けます。

⌘ を 2 回押して放すとリーダーモードになります。ウインドウが強調表示されている間は、続けて操作できます。Esc で終了します。

, / . — 列に 1 領域だけある場合は、左／右の列に結合します。上下分割した列では、選択中の領域を左／右の独立した列に分離します。スタック内のウインドウはまとめて移動します。

Space → J / X — 選択中のウインドウを同じ App のスタックに追加／スタックから外す

1–9 / ⇧1–9 — デスクトップ切替／ウインドウ移動

0 → 10–99 / ⇧0 — リーダーモードで 0 を押してから2桁の数字を入力すると、デスクトップ 10–99 に切り替わります。
