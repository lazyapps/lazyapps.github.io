## 产品简介

Calmon 将 Mac 窗口排成可滚动的列。支持同应用堆叠、固定列和桌面切换。鼠标或键盘都能操作。

macOS 26 或更新版本

多显示器建议上下排列。横向并排时，共享边缘会阻断滚动，切换列时会循环跳转。两侧都有显示器时，后台窗口会叠在当前窗口后方。

按 \` 可聚焦下一台显示器。按 Shift + \` 可将聚焦窗口移到该显示器的当前桌面，并跟随窗口切换过去。

Beta 期间免费

遇到问题或有想法，来 X 找 @lazyapps。谢谢你帮 Calmon 变得更好用。

窗口按列横向排列，随焦点滚动。在前导键模式中用方向键切换列。

一列可分成最多三个上下排列的区域，同时显示多个窗口。每个区域既可放一个窗口，也可放一组 App 堆叠。

同一 App 的平铺窗口默认重叠在同一区域，一次显示一个。点击窗口顶部的堆叠标记，或按 ⌘\` 切换。

在前导键模式中，先按空格，再按 J 将当前窗口加入同 App 堆叠，或按 X 将当前窗口移出堆叠。

将一列固定在左侧或右侧，其他窗口在旁边滚动。在前导键模式中按 Tab 切换焦点。

最多固定十个 App，各显示器共用顺序。点击 Pin Deck 标记添加 App。通过图标菜单移出 App。

Sky Deck 显示浮动窗口，Max Deck 显示原生全屏窗口。点击图标返回对应窗口。

点击桌面编号切换桌面。在前导键模式中按图标标签选择窗口。按 Shift 和 1–9 将窗口移到其他桌面。

点击标签栏图标选择窗口。按住 Control 点击图标打开窗口菜单。点击布局图打开按键面板。点击面板上的按键执行操作。

不想自动显示面板，可在「设置 → 键盘 → 按键面板 → 延迟显示」中选择「永不」。点击布局图仍会立即打开。

双击并松开 ⌘ 进入前导键模式。窗口有高亮框时，可连续执行命令。按 Esc 退出。

, / . — 独占一列时，并入左／右相邻列；同列有多个区域时，将当前区域拆成左／右独立列。区域中的整组堆叠会一起移动。

空格 → J / X — 将当前窗口加入／移出同 App 堆叠

1–9 / ⇧1–9 — 切换桌面／移至桌面

0 → 10–99 / ⇧0 — 在前导键模式中，先按 0，再输入两位数字，即可切换到桌面 10–99。

macOS 26: 辅助功能; macOS 27+: 设备控制和数据访问

需要辅助功能权限，用于移动窗口、调整大小和切换焦点。

不用。鼠标可完成全部窗口操作。点击布局图可随时打开按键面板。

轻扫默认关闭。可在「设置 → 手势」中启用三指或四指轻扫。轻扫前按住 Shift，可使用原有的 macOS 手势。 请在“系统设置”>“触控板”>“更多手势”中保持三指或四指手势开启。

标准窗口默认平铺。对话框、设置窗口和固定大小的窗口默认浮动。可在「设置 → 高级」中按 App 或标题添加规则。

只有主动移动时，窗口才会改变所属桌面。可用桌面编号或前导键模式切换桌面。退出 Calmon 时会恢复保存的窗口位置。
