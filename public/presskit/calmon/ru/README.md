## О приложении

Calmon размещает окна Mac в прокручиваемых столбцах. Собирайте окна в стопки, закрепляйте столбец и переключайтесь мышью или клавиатурой.

macOS 26 или новее

Разместите их друг над другом. При расположении рядом общие края блокируют прокрутку: переключение столбцов зацикливается на этих границах. Если мониторы с обеих сторон, фоновые окна накладываются друг на друга за выбранным окном.

\` переводит фокус на следующий дисплей. Shift + \` перемещает активное окно на текущий рабочий стол этого дисплея и переходит вслед за окном.

Бесплатно во время бета-тестирования

Нашли ошибку или есть идея? Напишите @lazyapps в X. Спасибо за помощь в улучшении Calmon.

Окна прокручиваются по горизонтали. Активный столбец занимает большую часть экрана. В режиме лидер-клавиши используйте стрелки.

Столбец можно разделить на три области, расположенные друг над другом и видимые одновременно. Каждая область содержит одно окно или стопку окон одного приложения.

Окна одного приложения перекрываются в одной области; одновременно видно только одно. Переключайтесь нажатием на отметки стопки вверху окна или сочетанием ⌘\`.

Режим лидер-клавиши: Space → J / X — Добавить выбранное окно в стопку его приложения / убрать из неё.

Закрепите столбец слева или справа. Другие окна прокручиваются рядом. Tab меняет фокус в режиме лидер-клавиши.

Закрепите до десяти приложений. Добавляйте через значок Pin Deck, удаляйте через меню иконки. Порядок одинаков на всех мониторах.

Sky Deck показывает плавающие окна, Max Deck — окна в системном полноэкранном режиме. Нажмите на иконку, чтобы вернуться к окну.

Нажмите на номер рабочего стола. В режиме лидер-клавиши введите метку иконки. Shift и 1–9 перемещают выбранное окно на другой рабочий стол.

Нажмите на иконку в панели вкладок, чтобы выбрать окно. Control-щелчок открывает действия с окном. Нажмите на карту расположения, чтобы открыть панель клавиш. Нажмите клавишу на панели для выполнения команды.

Отключение автопоказа панели: Настройки → Клавиатура → Панель клавиш → Показать через → Никогда. Карта расположения всегда открывает панель.

Дважды нажмите ⌘ и отпустите. Пока окно выделено, выполняйте команды подряд. Esc завершает режим.

, / . — Если область одна в столбце, присоединить её к столбцу слева / справа. В разделённом столбце — вынести активную область в отдельный столбец слева / справа. Вся стопка перемещается целиком.

0 → 10–99 / ⇧0 — В режиме лидер-клавиши нажмите 0, затем введите две цифры для перехода к рабочим столам 10–99.
