## เกี่ยวกับแอป

Calmon จัดหน้าต่าง Mac เป็นคอลัมน์ที่เลื่อนได้ ซ้อนหน้าต่าง ตรึงคอลัมน์ และสลับด้วยเมาส์หรือคีย์บอร์ด

macOS 26 ขึ้นไป

วางจอในแนวบนล่าง เมื่อวางข้างกัน ขอบร่วมจะขวางการเลื่อน และการสลับคอลัมน์จะวนกลับที่ขอบนั้น หากมีจอทั้งสองด้าน หน้าต่างเบื้องหลังจะซ้อนกันอยู่หลังหน้าต่างที่เลือก

ใช้ฟรีระหว่างเบต้า

พบข้อผิดพลาดหรือมีไอเดียไหม? บอก @lazyapps บน X ขอบคุณที่ช่วยปรับปรุง Calmon

Calmon ไม่มีไอคอนใน Dock ให้หาได้ที่แถบเมนู

หน้าต่างเลื่อนในแนวนอน คอลัมน์ที่เลือกใช้พื้นที่ส่วนใหญ่ของจอ ใช้ปุ่มลูกศรในโหมดคำสั่ง

หน้าต่างแบบไทล์จากแอปเดียวกันจะรวมเป็นกอง คลิกตัวบอกกองหรือกด ⌘` เพื่อสลับ หนึ่งคอลัมน์รองรับได้ถึงสามกอง

ตรึงคอลัมน์ไว้ที่ขอบซ้ายหรือขวา หน้าต่างอื่นจะเลื่อนข้างกัน ใช้ Tab สลับโฟกัสในโหมดคำสั่ง

ปักหมุดได้ถึงสิบแอป เพิ่มผ่านสัญลักษณ์ Pin Deck และเอาออกผ่านเมนูไอคอน ลำดับเหมือนกันบนทุกจอ

Sky Deck แสดงหน้าต่างลอย ส่วน Max Deck แสดงหน้าต่างเต็มหน้าจอแบบ macOS คลิกไอคอนเพื่อกลับไปยังหน้าต่าง

คลิกหมายเลขเดสก์ท็อป ในโหมดคำสั่งให้พิมพ์ป้ายไอคอน กด Shift กับ 1–9 เพื่อย้ายหน้าต่างที่เลือกไปเดสก์ท็อปอื่น

คลิกไอคอนในแถบแท็บเพื่อเลือกหน้าต่าง กด Control แล้วคลิกเพื่อเปิดการทำงานของหน้าต่าง คลิกแผนผังหน้าต่างเพื่อเปิดแผงปุ่ม คลิกปุ่มเพื่อเรียกใช้คำสั่ง

การช่วยการเข้าถึง เพื่อย้าย ปรับขนาด และเลือกหน้าต่าง

ไม่ต้อง ทุกการทำงานใช้เมาส์ได้ เปิดแผงปุ่มจากแผนผังหน้าต่าง

ค่าเริ่มต้นปิดไว้ เปิดการปัดสามหรือสี่นิ้วได้ที่ การตั้งค่า → คำสั่งนิ้ว กด Shift ค้างก่อนปัดเพื่อใช้คำสั่งนิ้วเดิมของ macOS

หน้าต่างมาตรฐานจะเรียงเป็นไทล์ ส่วนกล่องโต้ตอบ การตั้งค่า และหน้าต่างขนาดคงที่จะลอย เพิ่มกฎได้ที่ การตั้งค่า → ขั้นสูง

เฉพาะเมื่อคุณสั่งย้าย ใช้หมายเลขหรือโหมดคำสั่งสลับเดสก์ท็อป เมื่อออก Calmon จะคืนตำแหน่งหน้าต่างที่บันทึกไว้
