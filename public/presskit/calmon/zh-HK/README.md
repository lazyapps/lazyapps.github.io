## 產品簡介

Calmon 將 Mac 視窗排成可滾動的列。支持同應用堆疊、固定列和桌面切換。滑鼠或鍵盤都能操作。

macOS 26 或更新版本

多顯示器建議上下排列。橫向並排時，共享邊緣會阻斷滾動，切換列時會循環跳轉。兩側都有顯示器時，後台視窗會疊在當前視窗後方。

Beta 期間免費

遇到問題或有想法，來 X 找 @lazyapps。謝謝你幫 Calmon 變得更好用。

Calmon 不在 Dock 顯示圖標。可在選單列  找到它。

視窗橫向排列，隨焦點滾動。當前列佔據大部分屏幕。在前導模式中用方向鍵切換。

同一 App 的平鋪視窗自動堆疊。點擊堆疊標記或按 ⌘` 切換視窗。每列最多上下擺放三疊視窗。

將一列固定在左側或右側，其他視窗在旁邊滾動。在前導模式中按 Tab 切換焦點。

最多固定十個 App，各顯示器共用順序。點擊 Pin Deck 標記添加 App。通過圖標選單移出 App。

Sky Deck 顯示浮動視窗，Max Deck 顯示原生全屏視窗。點擊圖標返回對應視窗。

點擊桌面編號切換桌面。在前導模式中按圖標標籤選擇視窗。按 Shift 和 1–9 將視窗移到其他桌面。

點擊分頁列圖標選擇視窗。右鍵點擊圖標打開視窗選單。點擊佈局圖打開按鍵面板。點擊面板上的按鍵執行操作。

需要輔助使用權限，用於移動視窗、調整大小和切換焦點。

不用。滑鼠可完成全部視窗操作。點擊佈局圖可隨時打開按鍵面板。

輕掃默認關閉。可在「設定 → 手勢」中啓用三指或四指輕掃。輕掃前按住 Shift，可使用原有的 macOS 手勢。

標準視窗默認平鋪。對話框、設定視窗和固定大小的視窗默認浮動。可在「設定 → 高級」中按 App 或標題添加規則。

只有主動移動時，視窗才會改變所屬桌面。可用桌面編號或前導模式切換桌面。退出 Calmon 時會恢復保存的視窗位置。
