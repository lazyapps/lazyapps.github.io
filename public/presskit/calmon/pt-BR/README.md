## Sobre o app

O Calmon organiza janelas do Mac em colunas com rolagem. Empilhe janelas, fixe uma coluna e alterne com o mouse ou teclado.

macOS 26 ou posterior

Coloque os monitores na vertical. Lado a lado, as bordas compartilhadas bloqueiam a rolagem; a navegação entre colunas retorna ao início nesses pontos. Com monitores nos dois lados, as janelas de fundo se sobrepõem atrás da selecionada.

Grátis durante o beta

Encontrou um erro ou tem uma ideia? Fale com @lazyapps no X. Obrigado por ajudar a melhorar o Calmon.

As janelas rolam na horizontal. A coluna ativa ocupa quase toda a tela. Use as setas no modo líder.

Uma coluna pode ser dividida em até três áreas, uma acima da outra e visíveis ao mesmo tempo. Cada área contém uma janela ou uma pilha de janelas de um app.

As janelas do mesmo app ficam sobrepostas em uma área, com apenas uma visível por vez. Clique nos indicadores no topo da janela ou pressione ⌘` para alternar.

Modo Líder: Space → J / X — Adicionar / remover a janela selecionada da pilha do seu app.

Fixe uma coluna em uma das bordas. As outras janelas rolam ao lado. Tab alterna o foco no modo líder.

Fixe até dez apps. Adicione pela marca do Pin Deck e remova pelo menu do ícone. A ordem é igual em todos os monitores.

Sky Deck lista janelas flutuantes. Max Deck lista janelas em tela cheia nativa. Clique em um ícone para voltar à janela.

Clique no número de uma mesa. No modo líder, digite a etiqueta de um ícone. Shift e 1–9 movem a janela selecionada para outra mesa.

Clique em um ícone da barra de abas para selecionar a janela. Control-clique abre as ações da janela. Clique no mapa de layout para abrir o painel de teclas. Clique em uma tecla para executar o comando.

Para ocultar o painel automático: Ajustes → Teclado → Painel de Teclas → Mostrar após → Nunca. O mapa de layout sempre abre o painel.

Pressione ⌘ duas vezes e solte. Enquanto a janela estiver destacada, continue usando os comandos. Esc sai do modo.
