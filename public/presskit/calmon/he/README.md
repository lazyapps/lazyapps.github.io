## על היישום

Calmon מסדר חלונות Mac בעמודות נגללות. קבצו חלונות, קבעו עמודה ועברו בין חלונות עם העכבר או המקלדת.

macOS 26 ואילך

מקמו את הצגים זה מעל זה. בצגים זה לצד זה, הקצוות המשותפים חוסמים גלילה ומעבר העמודות חוזר להתחלה שם. כשיש צגים בשני הצדדים, חלונות הרקע חופפים מאחורי החלון הנבחר.

בחינם בתקופת הבטא

מצאתם תקלה או יש לכם רעיון? כתבו ל־@lazyapps ב־X. תודה על העזרה בשיפור Calmon.

החלונות נגללים אופקית. העמודה הפעילה תופסת את רוב המסך. השתמשו בחצים במצב המוביל.

אפשר לחלק עמודה לעד שלושה אזורים, זה מעל זה, שנראים בו־זמנית. כל אזור מכיל חלון אחד או ערמת חלונות של אותו יישום.

חלונות של אותו יישום חופפים באזור אחד, ורק אחד מוצג בכל פעם. לחצו על סימני הערמה בראש החלון או על ⌘` כדי לעבור ביניהם.

מצב המוביל: Space → J / X — הוספת החלון שנבחר לערמת היישום שלו / הוצאתו ממנה.

קבעו עמודה בקצה הימני או השמאלי. שאר החלונות נגללים לצדה. Tab משנה מיקוד במצב המוביל.

נעצו עד עשרה יישומים. הוסיפו דרך סימון Pin Deck והסירו מתפריט הצלמית. הסדר זהה בכל הצגים.

Sky Deck מציג חלונות צפים ו־Max Deck מציג חלונות במסך מלא של macOS. לחצו על צלמית כדי לחזור לחלון.

לחצו על מספר מכתבה. במצב המוביל הקלידו תווית צלמית. Shift עם 1–9 מעביר את החלון הנבחר למכתבה אחרת.

לחצו על צלמית בסרגל הכרטיסיות לבחירת חלון. לחיצה עם Control פותחת פעולות חלון. לחצו על מפת הפריסה לפתיחת לוח המקשים. לחצו על מקש לביצוע הפקודה.

לביטול הלוח האוטומטי: הגדרות ← מקלדת ← לוח המקשים ← הצגה אחרי ← אף פעם. מפת הפריסה תמיד פותחת את הלוח.

לחצו פעמיים על ⌘ ושחררו. כל עוד החלון מודגש, אפשר להמשיך בפקודות. Esc יוצא מהמצב.

, / . — כשהאזור לבד בעמודה: צירוף לעמודה משמאל / מימין. בעמודה מחולקת: הוצאת האזור הפעיל לעמודה נפרדת משמאל / מימין. הערמה כולה עוברת יחד.

Space → J / X — הוספת החלון שנבחר לערמת היישום שלו / הוצאתו ממנה

macOS 26: נגישות; macOS 27+: שליטה במכשיר וגישה לנתונים

נגישות להזזה, שינוי גודל ובחירת חלונות.

לא. כל הפעולות זמינות בעכבר. מפת הפריסה פותחת את לוח המקשים.

הן כבויות בהתחלה. הפעילו שלוש או ארבע אצבעות בהגדרות ← מחוות. החזיקו Shift לפני ההחלקה לשימוש במחוות macOS המקורית. יש להשאיר מחוות בשלוש או ארבע אצבעות פעילות בהגדרות המערכת > משטח מגע > מחוות נוספות.

חלונות רגילים כן. תיבות דו־שיח, הגדרות וחלונות בגודל קבוע צפים. הוסיפו כללים בהגדרות ← מתקדם.

רק כשאתם מעבירים אותם. עברו עם מספרי מכתבות או מצב המוביל. בסיום Calmon משחזר את מיקומי החלונות השמורים.

כן, Calmon בחינם בתקופת הבטא.

בחרו חיפוש עדכונים… בתפריט Calmon.
