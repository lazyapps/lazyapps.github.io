## 앱 소개

Calmon은 Mac 윈도우를 스크롤 가능한 열로 정리합니다. 윈도우를 쌓고 열을 고정하며 마우스나 키보드로 전환하세요.

macOS 26 이상

위아래로 배치하세요. 좌우로 배치하면 공유 경계에서 스크롤이 막히고 열 전환이 처음으로 돌아갑니다. 양쪽 모두에 디스플레이가 있으면 배경 윈도우가 선택한 윈도우 뒤에 겹칩니다.

베타 기간 무료

버그나 아이디어가 있나요? X의 @lazyapps에 알려 주세요. Calmon 개선에 도움을 주셔서 감사합니다.

윈도우가 가로로 스크롤됩니다. 활성 열이 화면 대부분을 차지합니다. 리더 모드에서 방향키로 이동하세요.

열을 위아래로 최대 세 영역으로 나누어 여러 윈도우를 동시에 볼 수 있습니다. 각 영역에는 윈도우 하나 또는 같은 앱의 윈도우 스택을 배치할 수 있습니다.

같은 앱의 윈도우를 한 영역에 겹쳐 놓고 한 번에 하나씩 표시합니다. 윈도우 위쪽의 스택 표시를 클릭하거나 ⌘`를 눌러 전환합니다.

리더 모드: Space → J / X — 선택한 윈도우를 같은 앱의 스택에 추가 / 스택에서 빼기.

열을 왼쪽이나 오른쪽 가장자리에 고정하세요. 다른 윈도우는 옆에서 스크롤됩니다. 리더 모드에서 Tab으로 초점을 전환합니다.

앱을 최대 10개 고정하세요. Pin Deck 표시로 추가하고 아이콘 메뉴에서 제거합니다. 순서는 모든 디스플레이에서 같습니다.

Sky Deck은 떠 있는 윈도우를, Max Deck은 macOS 기본 전체 화면 윈도우를 표시합니다. 아이콘을 클릭하면 돌아갑니다.

데스크탑 번호를 클릭하세요. 리더 모드에서 아이콘 레이블을 입력해 윈도우를 선택합니다. Shift와 1–9로 선택한 윈도우를 다른 데스크탑으로 옮깁니다.

탭 막대 아이콘을 클릭해 윈도우를 선택하세요. Control-클릭으로 윈도우 동작을 여세요. 레이아웃 맵을 클릭해 키 패널을 여세요. 패널의 키를 클릭해 명령을 실행하세요.

자동 패널을 끄려면 설정 → 키보드 → 키 패널 → 표시 지연 → 안 함을 선택하세요. 레이아웃 맵에서는 언제든 패널을 열 수 있습니다.

⌘를 두 번 누르고 놓으면 리더 모드가 됩니다. 윈도우가 강조되는 동안 명령을 연속으로 실행할 수 있습니다. Esc로 종료합니다.

, / . — 열에 영역이 하나뿐이면 왼쪽 / 오른쪽 열에 합칩니다. 분할된 열에서는 선택한 영역을 왼쪽 / 오른쪽의 독립된 열로 분리합니다. 스택의 모든 윈도우가 함께 이동합니다.

Space → J / X — 선택한 윈도우를 같은 앱의 스택에 추가 / 스택에서 빼기

macOS 26: 손쉬운 사용; macOS 27+: 기기 제어 및 데이터 접근

윈도우 이동, 크기 조절, 선택을 위해 손쉬운 사용 권한이 필요합니다.

아니요. 모든 동작을 마우스로 할 수 있습니다. 레이아웃 맵에서 키 패널을 여세요.

처음에는 꺼져 있습니다. 설정 → 제스처에서 세 손가락 또는 네 손가락을 켜세요. 쓸어넘기기 전에 Shift를 누르면 원래 macOS 제스처를 쓸 수 있습니다. 시스템 설정 > 트랙패드 > 추가 제스처에서 세 손가락 또는 네 손가락 제스처를 켜 두십시오.

일반 윈도우는 타일로 배치됩니다. 대화상자, 설정, 고정 크기 윈도우는 떠 있습니다. 설정 → 고급에서 규칙을 추가하세요.

직접 옮길 때만 이동합니다. 번호나 리더 모드로 데스크탑을 전환하세요. 종료 시 저장한 윈도우 위치를 복원합니다.

네, 베타 기간에는 무료입니다.

Calmon 메뉴에서 업데이트 확인…을 선택하세요.
