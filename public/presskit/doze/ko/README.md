## 앱 소개

자리 비움 시 화면 어둡게 하기 기능을 켜고 대기 시간을 선택하세요. 기본값은 10분입니다. 바로 어둡게 할 수도 있어요.

마우스나 트랙패드를 움직이거나 키를 누르면 됩니다. 검증한 AI 도구의 가상 클릭과 키 입력은 화면을 밝히지 않습니다. 다른 도구는 다르게 동작할 수 있어요.

화면 보호기와 화면 꺼짐을 막아 computer use 등 AI 데스크톱 작업에서 앱을 보고 조작할 수 있게 합니다.
자동 잠자기도 막아 다운로드와 내보내기를 계속합니다.

이 옵션을 켜도 화면은 설정에 따라 어두워집니다.

자리 비움 시 화면 어둡게 하기 기능을 켜고 대기 시간을 선택하세요.

AI가 컴퓨터를 계속 조작해야 한다면 “컴퓨터 깨어 있게 유지”를 켜세요.

Mac 내장 디스플레이와 Studio Display처럼 시스템에서 밝기를 조절할 수 있는 디스플레이를 지원합니다. 다른 외장 디스플레이의 작동은 보장하지 않습니다. 완전히 어두워지는지는 디스플레이에 따라 달라요.

네. 깨어 있게 유지하는 옵션은 두 동작을 막지 않습니다. 옵션을 끄거나 잠깐 쉼을 종료하면 이전 설정으로 돌아갑니다.

Doze는 독점 소프트웨어입니다. GitHub 저장소는 배포 파일과 제품 정보를 제공합니다.
