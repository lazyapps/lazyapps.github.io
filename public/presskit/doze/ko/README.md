자리 비움 시 화면 어둡게 하기 기능을 켜고 대기 시간을 선택하세요. 기본값은 10분입니다. 바로 어둡게 할 수도 있어요.

마우스나 트랙패드를 움직이거나 키를 누르면 됩니다. 검증한 AI 도구의 가상 클릭과 키 입력은 화면을 밝히지 않습니다. 다른 도구는 다르게 동작할 수 있어요.

화면 보호기와 화면 꺼짐을 막아 computer use 등 AI 데스크톱 작업에서 앱을 보고 조작할 수 있게 합니다.
자동 잠자기도 막아 다운로드와 내보내기를 계속합니다. 화면은 계속 어두워지지만 전력을 더 사용합니다.
