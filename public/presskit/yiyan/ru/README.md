## О приложении

Редактируйте тексты на Mac на естественном английском с объяснениями и примерами. Получайте новый ввод из инструментов ИИ для программирования, включая Claude Code и Codex, или редактируйте выделение и текущее поле. Доступна необязательная синхронизация iCloud с бета-версией для iPhone.

Редактируйте тексты на Mac на естественном английском с объяснениями и примерами. Получайте новый ввод из инструментов ИИ для программирования, включая Claude Code и Codex, или редактируйте выделение и текущее поле. Доступна необязательная синхронизация iCloud с бета-версией для iPhone.

Собирает новые сообщения из ИИ-инструментов для кода, не прерывая работу.

Вводите китайский, английский или смешанный текст. Улучшайте выделение или поле ввода в другом приложении.

Краткие пояснения и примеры. Задавайте вопросы по записи на Mac.

Американский или британский английский; естественный, разговорный или деловой стиль. Выбирайте язык пояснений и сохраняйте тон.

Просмотр по датам, избранное, копирование. Повторяйте неудачные попытки или удаляйте записи.

iCloud по желанию · бета iPhone в TestFlight. Озвучивание, активное вспоминание, ежедневные напоминания и переход в ИИ-приложения.

Pi · Claude Code · Codex · OpenCode · Antigravity. Собирает новый ввод во время работы, без импорта старых чатов. Использует установленного и доступного ассистента с выполненным входом. Отдельная настройка модели или API не нужна. Включите iCloud на Mac и используйте один Аккаунт Apple. На iPhone: поиск, календарь, избранное и офлайн-доступ к синхронизированным записям.

Записи локальные по умолчанию; iCloud включаете вы. Английский текст создаётся выбранным ИИ-сервисом. Фильтрует малоценные сообщения и скрывает уверенно распознанные секреты. Сохраняет код, пути и URL. Обсуждения на Mac остаются локальными, без синхронизации и экспорта. Данные облака можно удалить, сохранив записи Mac.

Заменяет выделенный текст; без выделения добавляет результат после оригинала. Нужен доступ к Универсальному доступу; есть меню Службы. Глобальные сочетания клавиш, поверх окон, прозрачность, светлая/тёмная тема, размер текста, автозапуск и автообновления. CLI только для чтения с экспортом записей. На iPhone копируйте контекст или открывайте ChatGPT, Claude, Gemini; отправляете вы сами.
