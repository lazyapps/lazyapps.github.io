## アプリについて

Mac で文章を自然な英語に推敲し、解説と例文を確認。Claude Code や Codex などの AI 開発ツールの新しい入力、選択した文章、現在の入力欄に対応。iCloud 同期を有効にすると iPhone ベータ版でも記録を確認できます。

Mac で文章を自然な英語に推敲し、解説と例文を確認。Claude Code や Codex などの AI 開発ツールの新しい入力、選択した文章、現在の入力欄に対応。iCloud 同期を有効にすると iPhone ベータ版でも記録を確認できます。

AI開発ツールへの新しい入力を自動取得。作業を止めません。

中国語・英語・混在文を直接入力。他のアプリの選択範囲や入力欄も推敲できます。

要点を絞った学習メモと例文。Macでは記録について続けて質問できます。

米式・英式、自然・カジュアル・専門的な文体。解説言語を選び、元の語調も維持できます。

日付で探す、お気に入り、コピーして再利用。失敗時の再試行や記録の削除も。

任意のiCloud同期 · iPhone TestFlightベータ版。読み上げ、想起練習、毎日の通知、AIアプリへの引き継ぎ。

Pi · Claude Code · Codex · OpenCode · Antigravity。起動中の新しい入力のみ取得し、過去の会話は取り込みません。 インストール・ログイン済みで利用可能なアシスタントを使用。モデルやAPIの追加設定は不要です。 MacでiCloudを有効にし、同じApple Accountを使用。iPhoneでは検索、カレンダー、お気に入り、同期済み記録のオフライン閲覧が可能。

記録は標準でローカル保存。iCloudは任意です。英語の生成には選択したAIサービスを使用します。 学習価値の低い入力を除外し、確度の高い秘密情報を伏せます。コード・パス・URLは保持します。 Macの追加質問はローカル限定で、同期・エクスポートされません。Macの記録を残してクラウドだけ削除できます。

選択範囲は置換し、未選択なら原文の後に追記。アクセシビリティ権限が必要です。サービスメニューにも対応。 グローバルショートカット、最前面表示、透明度、明暗テーマ、文字サイズ、ログイン時起動、自動更新。 読み取り専用CLIで記録を出力。iPhoneでは記録をコピー、またはChatGPT・Claude・Geminiを開き、自分で送信できます。
