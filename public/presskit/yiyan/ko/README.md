## 앱 소개

AI 코딩 도구의 새 입력을 자동 수집해 작업을 방해하지 않습니다.

중국어, 영어, 혼합 문장을 직접 입력하거나 다른 앱의 선택 영역과 입력란을 다듬으세요.

핵심 학습 노트와 예문. Mac에서 기록에 관해 이어서 질문하세요.

미국식·영국식, 자연스러운·편안한·전문적인 문체. 설명 언어를 고르고 원래 어조도 유지하세요.

날짜별 탐색, 즐겨찾기, 복사와 재사용. 실패한 작업 재시도와 기록 삭제도 가능합니다.

선택적 iCloud 동기화 · iPhone TestFlight 베타. 낭독, 기억 복습, 매일 알림, AI 앱으로 이어가기.

Pi · Claude Code · Codex · OpenCode · Antigravity. 실행 중 새 입력만 수집하며 이전 대화는 가져오지 않습니다. 설치·로그인되어 사용 가능한 도우미를 이용합니다. 별도 모델이나 API 설정은 필요 없습니다. Mac에서 iCloud를 켜고 같은 Apple 계정을 사용하세요. iPhone에서 검색, 달력, 즐겨찾기, 동기화한 기록의 오프라인 열람을 지원합니다.

기록은 기본적으로 로컬에 저장되며 iCloud는 선택 사항입니다. 영어 생성에는 선택한 AI 서비스를 사용합니다. 학습 가치가 낮은 입력을 걸러 내고 확실한 비밀 정보를 가립니다. 코드, 경로, URL은 유지합니다. Mac의 후속 대화는 로컬에만 보관되며 동기화·내보내기되지 않습니다. Mac 기록을 남기고 클라우드 데이터만 삭제할 수 있습니다.

선택한 텍스트는 교체하고, 선택 영역이 없으면 원문 뒤에 덧붙입니다. 손쉬운 사용 권한이 필요하며 서비스 메뉴도 지원합니다. 전역 단축키, 맨 위 고정, 투명도, 밝고 어두운 테마, 글자 크기, 로그인 시 실행, 자동 업데이트. 읽기 전용 CLI로 기록을 내보냅니다. iPhone에서 기록 맥락을 복사하거나 ChatGPT, Claude, Gemini를 열 수 있으며 전송은 직접 결정합니다.
