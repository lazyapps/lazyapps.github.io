## About the app

Refine text into natural English on Mac, with explanations and examples. Capture new input from AI coding tools such as Claude Code and Codex, or refine selected text and the current field. Optionally sync records via iCloud to the iPhone beta.

Refine text into natural English on Mac, with explanations and examples. Capture new input from AI coding tools such as Claude Code and Codex, or refine selected text and the current field. Optionally sync records via iCloud to the iPhone beta.

Capture new input from AI coding tools without interrupting your work.

Type Chinese, English or both. Refine a selection or the current text field in another app.

Focused notes and examples. Ask follow-up questions about a record on your Mac.

US or UK English; natural, casual or professional. Choose the explanation language and keep your tone.

Browse by date, bookmark, copy and reuse. Retry failures or delete records you no longer need.

Optional iCloud sync · iPhone TestFlight beta. Read aloud, practise recall, set daily reminders or continue in an AI app.

Pi · Claude Code · Codex · OpenCode · Antigravity. Captures new input while running; no old-chat import. Uses an installed, signed-in, available assistant. No separate model or API setup. Enable iCloud on Mac and use the same Apple Account. On iPhone: search, calendar, bookmarks and offline access to synced records.

Local records by default; you opt into iCloud. English generation still uses the selected AI service. Filters low-value input and redacts high-confidence secrets. Preserves code, paths and URLs. Mac follow-up chats stay local and are neither synced nor exported. Delete cloud data separately while keeping Mac records.

Refinement replaces selected text; with no selection, it appends after the original. Requires Accessibility permission; also available in Services. Global shortcuts, pinning, opacity, light/dark themes, text size, launch at login and automatic updates. Read-only CLI for record export. On iPhone, copy record context or open ChatGPT, Claude or Gemini; you choose when to send.
