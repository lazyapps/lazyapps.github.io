## About the app

Download X videos as MP4 files in Safari on Mac.

XVDL adds a download button when an X post provides a downloadable MP4. Save directly from Safari without copying links, opening converter websites or uploading media. It also supports Safari web apps saved with Add to Dock; enable the extension and website access in each web app’s settings.
