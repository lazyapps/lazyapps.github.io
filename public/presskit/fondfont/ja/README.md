## アプリについて

手持ちの TTF、OTF、TTC ファイルを iOS フォントライブラリにインストール。ZIP の読み込みに対応し、設定でインストールを完了すると Pages や Keynote などの対応アプリで使えます。

自分の文章で、サイズごとの見え方を確認。

文字の収録範囲、ファミリー、スタイル、ライセンス情報を確認。

同じ文章を使って、書体を並べて比較。

いつもの保存先から TTF・OTF・TTC・ZIP ファイルを開きます。

端末上でプロファイルを生成。ダウンロードを許可し、「設定」でインストールを完了します。

Pages、Keynote、Word、PowerPoint など、iOS のフォントライブラリに対応するアプリで選びます。

プロファイルは端末上で生成します。フォントファイルはアップロードしません。アカウントもサブスクリプションも不要です。

対応アプリ用のフォントをインストールします。iOS のシステム、キーボード、ホーム画面のフォントは変更できません。他のアプリにカスタムフォントの対応機能を追加することもできません。
