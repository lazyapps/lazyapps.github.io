## 产品简介

将自己的 TTF、OTF、TTC 字体安装到 iOS 字体库。支持导入 ZIP 字体包，在设置中完成安装后，可在 Pages、Keynote 等兼容 App 中使用。

将自己的 TTF、OTF、TTC 字体安装到 iOS 字体库。支持导入 ZIP 字体包，在设置中完成安装后，可在 Pages、Keynote 等兼容 App 中使用。

用你的文字，查看字体在不同字号下的表现。

检查字符覆盖、字族、样式及授权信息。

同一段文字，直观比较不同字体。

从日常存放字体的位置，打开 TTF、OTF、TTC 或 ZIP 文件。

爱装字体在本机生成描述文件。允许下载后，前往「设置」完成安装。

在支持 iOS 字体库的 App 中选择已安装字体，例如 Pages、Keynote、Word 和 PowerPoint。

爱装字体在本机生成描述文件。字体文件不会上传。无需账号或订阅。

爱装字体为兼容 App 安装字体。它不能修改 iOS 系统字体、键盘字体或主屏幕字体。它不能让其他 App 获得自定义字体支持。
