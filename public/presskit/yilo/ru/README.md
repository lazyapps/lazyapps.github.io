## О приложении

Учите языки на своих запросах к ИИ на Mac. Yilo предлагает естественные формулировки или переводы и при необходимости добавляет объяснения и примеры. Можно учить несколько языков одновременно.

Прежнее название — YiYan.

Yilo сохраняет ваши новые запросы к поддерживаемым ИИ-инструментам, если они полезны для изучения языка. Исходный запрос отправляется как обычно.

Выберите языки для изучения. Для каждого языка есть естественная формулировка или перевод.

Для каждого языка может быть до трёх заметок. На Mac можно задать вопросы по записи.

Введите текст или переформулируйте его в другом приложении. Переформулирование использует первый язык в учебном списке.

Ищите записи по дате, добавляйте в избранное и копируйте выражения. Неудачные записи можно обработать повторно, а ненужные — удалить.

Включите iCloud для чтения, озвучивания и повторения записей на iPhone. Есть ежедневные напоминания. Приложение для iPhone доступно через TestFlight.

Поддерживаются Pi, Claude Code, Codex, OpenCode и Antigravity. Yilo сохраняет новые запросы, пока запущен. Дополнительно настраивать модель или API не нужно.

Поддерживаются Pi, Claude Code, Codex, OpenCode и Antigravity. Yilo сохраняет только ваши новые запросы, пока программа запущена. Старые переписки не импортируются.

ИИ-инструмент должен быть установлен и доступен. Вам нужно войти в свою учётную запись в этом инструменте. Дополнительно настраивать модель или API не требуется.

Используйте один Аккаунт Apple на Mac и iPhone. С iCloud на iPhone доступны поиск, избранное и просмотр синхронизированных записей по дате. Читать можно и без сети.

По умолчанию записи хранятся на Mac; iCloud можно включить по желанию. Новые формулировки, переводы, заметки и уточняющие вопросы обрабатывает соответствующий ИИ-сервис.

По умолчанию записи остаются на Mac. iCloud включается по желанию. Переводы, заметки и уточняющие вопросы используют соответствующий ИИ-сервис.

Yilo отфильтровывает малополезные сообщения и скрывает секреты, распознанные с высокой уверенностью. Код, пути и URL сохраняются.

История переписки по учебным записям остаётся на Mac. Она не синхронизируется и не экспортируется. Можно удалить записи из облака, сохранив копии на Mac.

Вводите текст напрямую или редактируйте его в других приложениях. Для редактирования используется первый изучаемый язык и требуется разрешение универсального доступа.

В других приложениях результат заменяет выделенный текст. Если ничего не выделено, он добавляется сразу после исходного текста. Для этого нужно дать Yilo разрешение в разделе «Универсальный доступ». Функция также доступна через меню «Службы».

Настройте сочетания клавиш, закрепление окна, прозрачность, тему и размер текста. Есть запуск при входе и автоматические обновления.

Интерфейс командной строки работает в режиме чтения и позволяет экспортировать записи. На iPhone можно скопировать контекст записи или открыть ChatGPT, Claude или Gemini. Вы сами решаете, когда его отправить.

Изучайте несколько языков одновременно. Пиньинь, чжуинь, хирагана и ромадзи помогают читать.

Исходный язык сначала следует языку системы. Учебный язык по умолчанию — английский, а для английского оригинала — упрощённый китайский. Настройки можно изменить при первом запуске или позже. Число языков не ограничено.

Выберите язык объяснений, стиль и тон. Для английского доступны американский и британский варианты.

Китайские переводы могут показывать пиньинь или чжуинь. Для упрощённого китайского по умолчанию включён пиньинь, для традиционного — чжуинь. Пиньинь расположен над словами, чжуинь — справа от иероглифов. Подсказки можно отключить в настройках.

Японские переводы могут показывать хирагану или ромадзи. По умолчанию чтение выключено. Хирагана стоит над кандзи, ромадзи — над группами слов. Копируемый текст, заметки и результат переформулирования не меняются.
