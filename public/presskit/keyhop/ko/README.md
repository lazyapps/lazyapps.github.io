## 앱 소개

리더 키를 빠르게 두 번 누르고 홈 행의 키를 누르면, 해당 앱이 즉시 화면 맨 앞으로 나타나거나 실행됩니다.

macOS 홈 행의 고정 키에 최대 10개의 앱을 지정하세요. 리더 키를 빠르게 두 번 누르고 목표 키를 누르면 즉시 앱이 전환되거나 실행됩니다.

홈 행의 영구적인 실제 키 위치 10곳에 즐겨 쓰는 앱을 지정할 수 있습니다. 원하면 iCloud 동기화를 켜서 여러 Mac에서 같은 설정을 사용할 수 있습니다.

리더 키를 두 번 누르면 앱과 키의 대응을 반투명 패널로 확인할 수 있습니다. 앱을 선택하거나 취소할 때까지 표시됩니다. 키가 익숙해지면 설정에서 숨기고 근육 기억으로 이동하세요.

더블 탭 인식 간격을 150~600ms 사이로 세밀하게 조절하고, 설정 화면에서 바로 확인해 보세요.

Dock 공간을 차지하지 않습니다. 키 지정은 즉시 저장되며, 일시 정지 및 로그인 시 자동 실행을 지원합니다.

고정 키로 앱에 바로 이동하고, 단축키 안내는 숨길 수 있습니다. 윈도우를 관리하거나 입력 내용을 기록하지 않습니다.

macOS 26 이상을 실행하는 Apple Silicon Mac을 지원합니다. Developer ID로 서명되고 Apple 공식 공증을 거쳐 Mac App Store 외부에서 배포됩니다.
