## アプリについて

リーダーキーを素早く2回押して離し、ホームポジションのキーを叩くだけ。目的のアプリが瞬時に最前面へ現れます。

macOSのホームポジションの固定キーに最大10個のアプリを割り当て。リーダーキーを素早く2回押し、対応キーを打つだけで瞬時に切り替え・起動できます。

ホームポジションの固定キー10か所に、よく使うアプリを割り当てられます。必要に応じてiCloud同期を有効にすると、複数のMacで同じ設定を使えます。

リーダーキーを2回押すと、アプリとキーの対応を半透明のパネルで確認できます。アプリを選ぶかキャンセルするまで表示が続きます。キーを覚えたら、設定で非表示にして指の感覚で切り替えられます。

2回押しの判定間隔を150〜600msで微調整可能。設定画面で打ち心地を試しながら合わせられます。

Dockのスペースを消費しません。キー割り当ては即座に保存され、一時停止やログイン時起動にも対応。

固定キーでアプリに直行。対応表は非表示にもできます。ウインドウの管理や入力内容の記録はしません。

macOS 26以降を搭載したAppleシリコンMacに対応しています。Developer ID署名済み、Appleによる公証取得済みで、Mac App Store外から配布されます。
