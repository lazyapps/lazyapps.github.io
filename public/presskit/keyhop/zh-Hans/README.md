## 产品简介

连按两次触发键并松开，轻按主键行上的专属键位，即可切换或启动目标 App。

飞键把十个主键行键位变成固定的 App 快捷入口。连按两次触发修饰键并松开，轻按专属键位，即可切换或启动目标应用。

主键行提供十个触手可及的物理键位，每个键位固定绑定一个 App，形成可靠的肌肉记忆。可选择开启 iCloud 同步，在多台 Mac 上沿用同一套设置。

连按两次触发键，半透明面板便会显示 App 与键位对应，直到你选择应用或取消。记熟后也可以在设置中隐藏，凭肌肉记忆直达。

连按判定间隔支持 150–600 毫秒调节，也能在设置面板里即时测试手感。

不占 Dock 栏空间；按键映射即配即存，可随时一键暂停识别，亦支持开机自动启动。

固定键位直达 App，配合可隐藏的快捷键映射；不管理窗口，也不记录输入内容。

支持运行 macOS 26 或更高版本的 Apple 芯片 Mac。应用已通过 Developer ID 签名与 Apple 官方公证。
