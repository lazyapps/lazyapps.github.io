## 產品簡介

連按兩次觸發鍵並放開，輕按主鍵列上的專屬按鍵，即可瞬時切換或啟動目標 App。

飛鍵將十個主鍵列按鍵轉化為固定的 App 快捷入口。連按兩次觸發修飾鍵並放開，再輕按專屬按鍵，即可瞬時切換或啟動應用程式。

主鍵列提供十個觸手可及的實體鍵位，每個鍵位固定綁定一個 App，形成可靠的肌肉記憶。可選擇開啟 iCloud 同步，在多台 Mac 上沿用同一套設定。

連按兩次觸發鍵，半透明面板便會顯示 App 與鍵位對照，直到你選擇應用程式或取消。記熟後也可以在設定中隱藏，憑肌肉記憶直達。

連按判定間隔支援 150–600 毫秒調節，也能在設定面板裡即時測試手感。

不占用 Dock 空間；按鍵對應即設即存，可隨時一鍵暫停辨識，亦支援開機自動啟動。

固定鍵位直達 App，搭配可隱藏的快捷鍵對照；不管理視窗，也不記錄輸入內容。

支援執行 macOS 26 或更新版本的 Apple 晶片 Mac。App 已通過 Developer ID 簽署與 Apple 官方公證。
