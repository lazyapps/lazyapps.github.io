## アプリについて

iPhone・iPad で EPUB、CHM、MHT ファイルを読む。章をまたいだ検索、ハイライト、メモに対応。ローカル Wi-Fi で本を転送し、オフラインで読めます。

紙の背景やダークモードを選び、フォント、行間、余白を調整できます。

章をまたいで検索し、文章にハイライトやメモを追加。マークした箇所に戻れます。

EPUB、CHM、MHT ファイルを一つの本棚で管理。ローカル Wi-Fi で本を転送し、オフラインで読めます。

まずは無料で読書を。本が増えたら、一度のアプリ内購入で本棚の冊数制限を永久に解除できます。
