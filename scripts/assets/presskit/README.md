# Press Kit screenshot sources

Screenshot review dates are product-specific and recorded in `screenshot-sources.json`; Doze was recaptured on 2026-10-28. `screenshot-sources.json` records every catalog screenshot, original source, actual interface language, SHA-256, review date and app source revision. Review dates are not capture dates. Private projects are evidence only; all files needed to build the site are kept in this repository.

App language coverage is recorded in `src/content/presskit-supported-languages.json`: CHMate 15; FondFont 7; KeyHop 10; Yilo 12; Doze 12; Shheep 11; World Book and XVDL English only. Shared images are stored once at the archive root, with their actual interface language identified in each localized README. Native icons and promotional artwork have separate provenance; screenshots do not grant standalone rights to third-party content shown inside the apps.

When app UI changes, review and replace affected screenshots, update their provenance and localized asset notes, regenerate with `python3 scripts/prepare-presskits.py`, then run `npm run build`. The build rejects missing source reviews, changed screenshot hashes, mismatched output files and stale ZIP contents. It does not infer freshness from file modification times or access private app projects.
