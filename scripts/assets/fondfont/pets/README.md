# Professional pet trial — 2026-10-07

These are local evaluation assets, outside `public/`. They are served only by
the Vite development middleware at `/__fondfont_pet_trial/{dog,cat}.glb`.
Middleware rejects non-loopback peers; run the development server on 127.0.0.1.
Use `/fondfont/zh-hans/?pets=studio` to compare them in the actual hero.
Production builds retain the existing garden pet rig and do not copy these files.

## Rebuild

Run Blender 5.2.2 with `--disable-autoexec`:

```sh
/Applications/Blender.app/Contents/MacOS/Blender -b --disable-autoexec --python scripts/build-fondfont-studio-pets.py -- dog
/Applications/Blender.app/Contents/MacOS/Blender -b --disable-autoexec --python scripts/build-fondfont-studio-pets.py -- cat
```

Compress each `trial/{kind}-raw.glb` with glTF Transform `meshopt` into
`trial/{kind}.glb`. Preserve hierarchy: do not flatten or join the pet roots.
Then run `node scripts/check-fondfont-studio-pets.mjs`.

The original rigs have no finished walking clips. The builder poses their native
controllers, evaluates all cage/lattice/corrective deformation, and bakes 16 walk
poses plus two additive tail offsets. Autumn's sole controllers translate the
paws; similarly named IK controls are foot-roll pivots and must not replace them.
Runtime cadence follows signed travel distance. Diffuse baking excludes lighting;
exported source paint-mask attributes are removed to prevent double tinting.

## Acceptance boundary

Actual GLBs are 1.62 MB dog / 3.03 MB cat. Native paw target residuals are below
0.001 mm; exported lowest body surfaces remain within 1.6 mm of ground over all
16 samples. These are geometry checks, not proof of perfect visible locomotion.
An actual browser recording covers multiple straight strides and dog tail wag.
Original parent groom strands are retained as 3D geometry (5,092 dog / 1,834 cat),
but child hairs and the full Cycles fur shader are omitted; the web coat is less
dense than the source render. Dedicated pivot turns, play, sniff and potty poses
have not been migrated. This is a local visual trial, not a production replacement
with complete action parity. Existing production actions are preserved.

The local Autumn trial now uses a warm yellow coat via a body/groom material
color remap in `studio-pet-animation.ts`. Original coat variation is retained;
dark nose and saturated mouth pixels are excluded. Eyes and red neckerchief use
their original separate materials. Source meshes and embedded textures are
unchanged. Actual browser close view: `dog-golden-coat.png` in the trial review.


## Current v3 turning trial and local default

The local site now loads these pets by default, without `pets=studio`.
The original publication/license boundary above remains. Original18-pose
files are retained as `trial/{kind}-locomotion-v1.glb`.

Rebuild84-pose turning assets with Blender5.2.2:

```sh
/Applications/Blender.app/Contents/MacOS/Blender -b --disable-autoexec --python scripts/refine-fondfont-studio-turns-v3.py -- dog
/Applications/Blender.app/Contents/MacOS/Blender -b --disable-autoexec --python scripts/refine-fondfont-studio-turns-v3.py -- cat
```

Compress `trial/{kind}-turn-v3-raw.glb` to `{kind}-turn-v3.glb` using meshopt
16-bit positions, then copy to `trial/{kind}.glb`. Preserve named morphs and
hierarchy. Actual compressed sizes are about4.99MB dog and9.30MB cat.
`studio-pet-locomotion.ts` now uses forward-only gait advancement, native pivot
banks, timed swing/contact anchors and finite paw-heading correction. It
supersedes the signed-distance runtime and missing-turn limitations above.
Full bespoke play/sniff/potty poses remain outside this trial.

Current evidence/limits are in
`docs/reviews/fondfont-studio-turns-20261007/findings.md`.

## Production default: licensed calico replacement — 2026-10-08

The previous sections document historical private trials. The restricted
BlenderKit Domestic Cat is no longer loaded. It remains outside `public/`.
The public default now combines `public/v/fondfont/pets/dog-v3.glb` (Autumn)
with `cat-v1.glb` (JonasDichelle's Rigged and animated Cat, CC BY 3.0).
There is no DEV-only gate or `pets=studio` requirement, and the old private
asset-serving middleware was removed.

Cat source, original license and checksums: `calico-cat/`. Rebuild with:

```sh
/Applications/Blender.app/Contents/MacOS/Blender -b --disable-autoexec --python scripts/build-fondfont-calico-cat.py
```

Compress `calico-cat/cat-web-v1-raw.glb` with glTF Transform meshopt, 16-bit
position quantization, to `public/v/fondfont/pets/cat-v1.glb`. Keep all hierarchy,
named morph targets and extras. Copy Autumn's existing `trial/dog-turn-v3.glb`
to `public/v/fondfont/pets/dog-v3.glb`. Run `check-fondfont-studio-pets.mjs`.

The new cat uses its original mesh, packed coat painting, eyes and 1,151 combed
parent strands. Its native IK is adapted to grounded walk/pivot/plant poses;
the authored Walk action is not exported unchanged. Triangle frames bind the
groom's orientation and deformation. Web fur is less dense than Cycles hair.
Both pets have 84 evaluated native morph targets. Source files stay unchanged.
Localized footer credits and `public/v/fondfont/pets/CREDITS.txt` identify both
assets, exact licenses and actual modifications. Seven posters were refreshed.
